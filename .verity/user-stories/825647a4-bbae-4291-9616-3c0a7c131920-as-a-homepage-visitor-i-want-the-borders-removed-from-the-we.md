## Description

Homepage visitors (both new and returning users) currently see borders around the 'Welcome' text on the homepage. Removing these borders will create a cleaner, more modern appearance and improve the overall user experience. This change ensures that the homepage looks visually appealing and uncluttered, aligning with contemporary UI standards and potentially increasing user engagement.

## Acceptance Criteria

- [ ] Given I am on the homepage, When the page loads, Then the 'Welcome' text should not have any visible borders around it.
- [ ] Given I previously saw borders around the 'Welcome' text, When I refresh or revisit the homepage, Then the borders should no longer be present.
- [ ] Given I inspect the 'Welcome' text element, When I check its CSS properties, Then there should be no border-related styles applied.
