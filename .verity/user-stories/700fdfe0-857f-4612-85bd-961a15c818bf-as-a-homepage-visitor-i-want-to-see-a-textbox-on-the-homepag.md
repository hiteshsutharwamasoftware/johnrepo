## Description

As a general user visiting the homepage, I want a textbox to be available so that I can input information directly from the main landing page. This enables quick access to core functionality (such as search, feedback, or data entry) without navigating deeper into the site, improving user engagement and reducing friction. The textbox should be prominently placed and accessible to all users upon landing on the homepage.

## Acceptance Criteria

- [ ] Given I am on the homepage, When the page loads, Then I should see a textbox displayed prominently on the page.
- [ ] Given I am on the homepage, When I focus on the textbox, Then I should be able to type text into it.
- [ ] Given I am on the homepage, When I view the page on both desktop and mobile devices, Then the textbox should be visible and usable on all supported screen sizes.
