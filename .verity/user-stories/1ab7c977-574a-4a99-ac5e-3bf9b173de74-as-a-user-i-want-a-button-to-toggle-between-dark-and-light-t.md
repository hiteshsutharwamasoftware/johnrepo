## Description

End users of the application need the ability to switch between dark and light theme modes via a dedicated button in the user interface. This feature enhances accessibility and user comfort, allowing users to choose a visual style that suits their preferences or environmental lighting conditions. Providing a theme toggle improves user satisfaction and can reduce eye strain, especially in low-light environments. The button should be easily accessible and its state should persist across sessions if possible.

## Acceptance Criteria

- [ ] Given the user is logged in and viewing the main dashboard, When the user clicks the theme toggle button, Then the application theme switches between dark and light modes immediately.
- [ ] Given the user has selected a theme mode, When the user navigates to another page within the application, Then the selected theme mode remains active.
- [ ] Given the user has selected a theme mode, When the user refreshes the browser or returns to the application later, Then the previously selected theme mode is retained.
