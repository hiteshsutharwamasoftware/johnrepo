## Description

End users of the application want the ability to switch between dark and light theme modes via a dedicated toggle button in the user interface. This feature enhances accessibility and user comfort, allowing individuals to choose a visual theme that best suits their environment or personal preference. Providing theme toggling improves user satisfaction, reduces eye strain in low-light conditions, and aligns the application with modern UI standards. The toggle should be easily accessible and persist the user's choice across sessions.

## Acceptance Criteria

- [ ] Given the user is on any page of the application, When the theme toggle button is visible, Then the user can click it to switch between dark and light modes instantly.
- [ ] Given the user has selected a theme mode, When they navigate to another page or refresh the browser, Then the selected theme mode persists and remains active.
- [ ] Given the application is loaded for the first time, When the user has not previously selected a theme, Then the default theme mode is applied (as defined by system or app default).
