## Description

As a first-time or returning visitor to the application, I want the homepage to present a clean interface that displays only a simple 'Welcome' message. This helps reduce distractions, provides a clear starting point, and supports a minimalistic user experience. The goal is to temporarily remove all other UX elements from the homepage, ensuring users see only the 'Welcome' message upon arrival.

## Acceptance Criteria

- [ ] Given I navigate to the homepage, When the page loads, Then I see only a 'Welcome' message displayed prominently.
- [ ] Given I am on the homepage, When I look for navigation menus, buttons, or other UI elements, Then none are present except the 'Welcome' message.
- [ ] Given I refresh or revisit the homepage, When the page reloads, Then the interface remains clean with only the 'Welcome' message visible.
