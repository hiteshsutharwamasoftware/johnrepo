## Description

End users of the application want the ability to switch between light and dark visual themes via a toggle button. This feature enhances accessibility and user comfort, allowing users to select a theme that best suits their environment or personal preference. Providing theme toggling improves user satisfaction and can help reduce eye strain, especially in low-light conditions. The toggle should be easily accessible and persist the user's choice across sessions.

## Acceptance Criteria

- [ ] Given I am on any page of the application, When I click the theme toggle button, Then the application should switch between light and dark themes immediately.
- [ ] Given I have selected a theme (light or dark), When I refresh or revisit the application, Then my previously selected theme should be retained and automatically applied.
- [ ] Given the application is displayed on both desktop and mobile devices, When I use the theme toggle button, Then the theme should update consistently across all supported devices and screen sizes.
