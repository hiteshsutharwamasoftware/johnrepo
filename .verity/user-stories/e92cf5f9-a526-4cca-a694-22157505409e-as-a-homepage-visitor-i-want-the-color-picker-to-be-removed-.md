## Description

Homepage visitors and users currently see a color picker component on the homepage. The goal is to remove this color picker to simplify the user interface and reduce distractions, ensuring a cleaner and more focused homepage experience. This change is intended to improve usability and align the homepage with current design guidelines. No other parts of the application should be affected.

## Acceptance Criteria

- [ ] Given a user visits the homepage, When the page loads, Then the color picker component should not be visible anywhere on the homepage.
- [ ] Given a user interacts with the homepage, When searching for customization options, Then there should be no option to change colors via a color picker.
- [ ] Given the homepage is rendered, When inspecting the page structure, Then no color picker-related code or elements should be present in the DOM.
