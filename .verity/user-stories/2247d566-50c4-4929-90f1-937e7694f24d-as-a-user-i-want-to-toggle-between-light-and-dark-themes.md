## Description

End users of the application need the ability to switch between light and dark themes via a button in the user interface. This feature enhances accessibility and user comfort, allowing individuals to choose the visual mode that best suits their environment or personal preference. Providing a theme toggle increases user satisfaction and aligns the application with modern UX standards. The button should be easily accessible and its state should persist across sessions.

## Acceptance Criteria

- [ ] Given the user is logged into the application, When they view the main navigation bar, Then a theme toggle button is visible.
- [ ] Given the user is on any page, When they click the theme toggle button, Then the application's theme switches between light and dark modes immediately.
- [ ] Given the user has selected a theme, When they refresh or revisit the application, Then their chosen theme persists and is automatically applied.
