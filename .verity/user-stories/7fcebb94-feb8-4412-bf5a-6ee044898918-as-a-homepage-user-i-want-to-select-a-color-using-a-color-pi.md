## Description

Homepage visitors (end users) want the ability to choose a color directly from the homepage using a color picker component. This feature enables users to personalize their experience, select theme colors, or preview color-related functionality, depending on the homepage's purpose. Providing a color picker improves user engagement and supports customization or design workflows. The color picker should be easily accessible, intuitive to use, and visually integrated with the homepage layout.

## Acceptance Criteria

- [ ] Given I am on the homepage, When I view the main content area, Then I should see a color picker component clearly displayed.
- [ ] Given the color picker is visible, When I select a color, Then the selected color value should be immediately reflected in the UI (e.g., preview area, background, or designated element).
- [ ] Given I have selected a color, When I refresh the homepage, Then the color picker should reset to its default state (unless persistent selection is a requirement).
